# تطبيق «تعالَ نؤمن ساعة» — حلقة سيدنا أبو بكر الصديق

تطبيق ويب متكامل (Full-Stack) باللغة العربية (RTL) مخصص لمتابعة البرنامج التطوعي لمدة **30 يوماً** لطلاب **حلقة سيدنا أبو بكر الصديق**، لتسجيل ثلاثة أعمال يومية والتعاون على المواظبة والتشجيع المتبادل تحت شعار:
> «نتنافس على المواظبة، والنقاط لا تقيس صلاح أحد أو إخلاصه.»

---

## 1. المعمارية والتقنيات المستخدمة

* **الواجهة الأمامية (Frontend):** React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons، بتصميم متجاوب يعطي الأولوية لشاشات الهواتف (360px فما فوق) مع تخطيط عربي أصيل (RTL).
* **قاعدة البيانات والمصادقة (Backend & Auth):** Supabase (PostgreSQL 15+، مصادقة البريد الإلكتروني وكلمة المرور `Email + Password` بدون الحاجة لإعدادات Google Cloud المعقدة، بالإضافة إلى دعم Google OAuth عند الرغبة، مع سياسات أمن الصفوف Row Level Security ودوال `SECURITY DEFINER` محمية بمسار بحث آمن `SET search_path = public, pg_temp`).
* **التوقيت المعتمد:** يتم حساب تاريخ اليوم وحدود منتصف الليل حصرياً بتوقيت دمشق (`Asia/Damascus`) على مستوى خادم قاعدة البيانات عبر الدالة `public.get_damascus_today()`.
* **النشر والاستضافة (Deployment):** مُهيأ بالكامل للنشر على **Vercel** (`vercel.json`) أو **Netlify** (`netlify.toml`).

---

## 2. خطوات الإعداد السريع في Supabase (دون الحاجة إلى Google Cloud Console)

بما أنك قمت بتشغيل ملفات الهجرة الأربعة في **SQL Editor** وتم تسجيل بريد المشرف `hajij94@gmail.com`، لم يتبقَّ داخل Supabase سوى خطوة واحدة تستغرق 10 ثوانٍ:

1. في لوحة تحكم **Supabase**، افتح **Authentication** من القائمة اليسرى ثم اضغط **Providers**.
2. اضغط على **Email** (وهو مفعّل افتراضياً).
3. قم بإيقاف خيار **Confirm email** (اجعله **OFF**) ثم اضغط **Save**.
   * **لماذا؟** حتى يتمكن طلاب الحلقة الـ 20 من إنشاء حساباتهم والدخول فوراً دون انتظار رسائل التفعيل أو الاصطدام بحدود إرسال البريد المجاني، بينما تتكفل شاشة **«بانتظار موافقة المشرف»** بحماية خصوصية الحلقة حتى توافق عليهم بنفسك من لوحة المشرف.

## 3. خطوات النشر على Vercel (3 دقائق)

1. **نسخ مفاتيح الربط العامة من Supabase:**
   * في لوحة تحكم **Supabase**، افتح **Project Settings** (أيقونة الترس أسفل القائمة اليسرى) -> **API**.
   * انسخ **Project URL** (`https://....supabase.co`).
   * انسخ مفتاح **`anon` `public`** (لا تستخدم مفتاح `service_role` أبداً).

2. **رفع المشروع ونشره على Vercel:**
   * فك ضغط ملف `taala-numin-saa-fullstack.zip` على جهازك، وارفع مجلد `taala-numin-saa` إلى مستودع GitHub خاص بك (أو شغّل `npx vercel` من داخل المجلد).
   * في موقع **Vercel** -> **Add New Project**، اختر المستودع، وفي قسم **Environment Variables** أضف المتغيرين التاليين:
     * `VITE_SUPABASE_URL` = رابط المشروع الذي نسخته من Supabase
     * `VITE_SUPABASE_ANON_KEY` = مفتاح `anon public` الذي نسخته من Supabase
   * اضغط **Deploy**.

3. **تسجيل دخولك كمشرف عام وبدء التحدي:**
   * افتح رابط التطبيق المنشور على Vercel.
   * اختر **«إنشاء حساب جديد»** أول مرة فقط وسجّل باستخدام بريدك `hajij94@gmail.com` وكلمة مرور من اختيارك.
   * سيتعرف النظام تلقائياً على بريدك `hajij94@gmail.com` ويمنحك صلاحية **«لوحة المشرف»** فوراً، ومنها يمكنك تحديد تاريخ بدء التحدي واعتماد طلبات انضمام طلاب الحلقة.
